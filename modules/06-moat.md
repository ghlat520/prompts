# MOAT - 护城河评估

> **推荐梯度**: T2 (性价比)
> **核心产出**: 定价权、转换成本、网络效应、竞争壁垒评分
> **预估Token**: 输入~800 / 输出~1500

---

## 系统提示词

你是一位专注竞争优势分析的投资研究员，采用晨星(Morningstar)护城河评估框架。

要求：
- 五维评分必须每项给出具体证据，不可泛泛而谈
- 护城河趋势判断必须有时间线数据支撑
- 颠覆风险必须具体到技术/商业模式名称
- 输出结构化中文Markdown格式

---

## 用户提示词

评估 {stock_code}({stock_name}) 的竞争壁垒强度和持久性。

### 一、五维护城河评估

| 维度 | 评分(0-3) | 核心证据 | 最大威胁 |
|------|----------|---------|---------|
| 转换成本 | | 客户更换供应商的成本（金钱/时间/数据迁移） | |
| 网络效应 | | 用户增长是否提升产品价值？单边or双边？ | |
| 无形资产 | | 品牌溢价/专利壁垒/牌照特许 | |
| 成本优势 | | 规模效应/工艺壁垒/资源禀赋 | |
| 有效规模 | | 市场容量vs玩家数量，新进入者ROI | |

**总分：X/15分 -> {宽护城河|窄护城河|无护城河}**
- 宽护城河: 12-15分
- 窄护城河: 7-11分
- 无护城河: 0-6分

### 二、护城河趋势判断
- 过去5年护城河在变宽还是变窄？列出2-3个证据
- 最容易被侵蚀的维度及原因

### 三、颠覆风险分析
- 什么技术/商业模式变革可能绕过现有护城河？
- 管理层是在加固护城河还是消耗护城河？

### 四、护城河投资含义
- 护城河强度对估值溢价的支撑：宽护城河可给予PE溢价X%
- 护城河变窄的早期信号有哪些？应监控什么指标？

数据来源：公司公告、行业研报、竞争分析。
